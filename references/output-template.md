# Output Template

The final output is a single `.md` file in the same directory as the source materials.

## File Naming

```
YYYY-MM-DD-第X讲-主题简述.md
```

Example: `2026-05-09-第7-9节-公共品供给理论.md`

## 时间戳与说话人（2026-09-28 起）

- 逐字稿由 `scripts/transcribe_diarize.py` 生成，产出 `逐字稿.md`（按轮次：`[HH:MM:SS] **说话人N**　正文`）、
  `逐字稿.json`（全局时间轴）与 `说话人对照表.md`（编号 ↔ 判断依据）。
- 笔记里的 `### [HH:MM:SS–HH:MM:SS]` **取 segments 的真实 start/end**，不再按片长估算。
- **笔记正文不留说话人编号**。对内容有意义的师生对话写成角色（`**学生提问**` / `**老师**`）
  或叙述句；要回溯“这句谁说的”，去查 逐字稿.md 与该讲的《说话人对照表》。
- 笔记顶部除逐字稿外，若转写走了说话人分离，**同时链接说话人对照表**。

## 🧮 数学模型推导

### 模型1：{模型名称}

**环境设定**
- {经济主体：消费者/厂商/政府}
- {商品/要素}
- {时间范围：静态/两期/无限期}

**假设**
1. {假设1}
2. {假设2}
3. ...

**模型建立**

{效用函数/生产函数}

$$
U = \sum_{i=1}^{n} u_i(x_i, G)
$$

**变量说明**（每个公式首次出现时必须附）

| 符号 | 含义 | 性质 |
|------|------|------|
| $u_i$ | 消费者 $i$ 的效用函数 | 严格递增、凹 |
| $x_i$ | 私人品消费量 | 实数 |
| $G$ | 公共品数量 | 实数（非竞争性） |
| $n$ | 消费者总数 | 正整数 |

{约束条件}

$$
\begin{aligned}
\text{s.t.} \quad & \sum_{i=1}^{n} p x_i + c(G) \leq \sum_{i=1}^{n} y_i
\end{aligned}
$$

**推导过程**

{最优化问题}

$$
\max_{x_i, G} \quad \sum_{i=1}^{n} u_i(x_i, G) \quad \text{s.t.} \quad \sum_{i=1}^{n} p x_i + c(G) \leq \sum_{i=1}^{n} y_i
$$

{拉格朗日函数}

$$
\mathcal{L} = \sum_{i=1}^{n} u_i(x_i, G) + \lambda \left( \sum_{i=1}^{n} y_i - \sum_{i=1}^{n} p x_i - c(G) \right)
$$

{一阶条件 (FOC)}

$$
\begin{aligned}
\frac{\partial \mathcal{L}}{\partial x_i} &= \frac{\partial u_i}{\partial x_i} - \lambda p = 0 \quad \forall i \\
\frac{\partial \mathcal{L}}{\partial G} &= \sum_{i=1}^{n} \frac{\partial u_i}{\partial G} - \lambda c'(G) = 0
\end{aligned}
$$

{关键推导步骤的解释}

{整理得到核心条件}

$$
\boxed{\sum_{i=1}^{n} \frac{\partial u_i / \partial G}{\partial u_i / \partial x_i} = c'(G)}
$$

即：

$$
\boxed{\sum_{i=1}^{n} MRS_{G,x}^i = MRT_{G,x}}
$$

> 其中 $MRS_{G,x}^i$ 为消费者 $i$ 在公共品 $G$ 与私人品 $x$ 之间的边际替代率，$MRT_{G,x}$ 为边际转换率（公共品以私人品计价的边际成本）。

- {与竞争均衡的对比}
- {政策含义}
